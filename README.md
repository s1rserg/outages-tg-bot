# Черкасиобленерго · Telegram-бот

Telegram-бот перевіряє публічну стрічку кожні 5 хвилин. Бот відстежує уманський графік для підчерги кожного підписника. Бот перечитує видимі дописи, включно з редагуваннями, які вже відображає Telegram. Якщо тимчасовий графік опубліковано без дати, сповіщення також буде без дати.

## Деплой на Cloudflare Workers Free

1. Створіть бота через @BotFather. Виконайте `npx wrangler login`.
2. Виконайте `npx wrangler d1 create outages-tg-bot`. Запишіть отриманий `database_id` у `wrangler.toml`.
3. Виконайте `npx wrangler d1 migrations apply outages-tg-bot --remote`, потім `npx wrangler deploy`.
4. Додайте токен через `npx wrangler secret put BOT_TOKEN`. Згенеруйте окремий випадковий секрет командою `openssl rand -hex 32` і додайте його через `npx wrangler secret put WEBHOOK_SECRET`.
5. Зареєструйте вебхук через Telegram Bot API. Перед виконанням введіть токен і секрет у змінні через команди нижче.

```bash
read -rsp 'Bot token: ' BOT_TOKEN; echo
read -rsp 'Webhook secret: ' WEBHOOK_SECRET; echo
read -rp 'Worker HTTPS origin: ' WORKER_URL
curl --fail-with-body -sS -X POST "https://api.telegram.org/bot${BOT_TOKEN}/setWebhook" \
  --data-urlencode "url=${WORKER_URL%/}/telegram" \
  --data-urlencode "secret_token=${WEBHOOK_SECRET}" \
  --data-urlencode 'allowed_updates=["message"]'
unset BOT_TOKEN WEBHOOK_SECRET WORKER_URL
```

Після `{"ok":true,...}` надішліть боту `/start`. Протягом наступного запуску перевірте журнал через `npx wrangler tail` і записи у D1. Команда `/stop` видаляє підписку та її заплановані повідомлення. Worker надсилає до 10 очікуваних повідомлень за один запуск. Через тимчасові помилки Telegram доставка повторюється на наступному запуску.

## Команди бота
 
Після /start бот показує кнопки керування в чаті. Кнопка «Обрати підчергу» відкриває список доступних підчерг. Кнопка «Довідка» або команда /help показує пояснення.

- `/start` активує підписку з підчергою 2.2 за замовчуванням або зберігає поточний вибір активного підписника.
- `/today` показує графік на сьогодні для вибраної підчерги. Бот також показує його після підключення чи зміни підчерги.
- `/queue` показує поточну підчергу.
- `/queue 3.1` змінює підчергу для обох графіків. Доступні підчерги від 1.1 до 6.2.
- `/stop` вимикає розсилку.

Для оновлення вже розгорнутого бота застосуйте міграцію 0002 перед деплоєм нового коду. Наявні підписники зберігають підчергу 2.2.

Кожен графік має окрему 24-годинну PNG-діаграму 480×480. Два графіки надходять одним альбомом із підписом для обох. Червоне позначає години відключень, зелене — решту доби. Недатований уманський графік має окрему позначку в підписі. Якщо Telegram відхиляє картинку, бот надсилає текст.

## Запасний парсер Gemini

Поточний парсер працює без ключа. Щоб увімкнути Gemini для незнайомих текстових дописів, застосуйте міграції, задеплойте код і збережіть ключ як секрет Worker:

```bash
npx wrangler d1 migrations apply outages-tg-bot --remote
npx wrangler deploy
npx wrangler secret put GEMINI_API_KEY
```

За замовчуванням використовується Gemini 3.5 Flash Lite. Для зміни моделі можна встановити змінну Worker `GEMINI_MODEL`. До Google надсилається публічний текст допису та його дата публікації. Перевірений результат кешується за ID і текстом допису. Запасний парсер застосовує часткову зміну, якщо допис явно називає старий і новий інтервали та старий інтервал є у збереженому графіку.

Після оновлення застосуйте міграцію 0004. Вона видаляє обласні графіки та їхні очікувані розсилки. Оголошення для Уманського району про відхилення й аварійні перебої обробляються окремо від таблиць та надсилаються підписникам із посиланням на джерело. Повторний текст не розсилається. Підсумок годин розраховано за збереженими інтервалами, без подвійного підрахунку перетинів.

## Історія дня й нагадування

Застосуйте міграцію 0005 перед деплоєм. Бот зберігає джерела графіків і відновлює день у порядку дописів. У скороченому оновленні зберігаються попередні інтервали, які вже завершилися до часу публікації. Майбутні інтервали беруться з оновлення. Без початкового графіка підсумок часу зі світлом позначається як невідомий. Це відновлення опублікованого плану, а не вимірювання фактичного електропостачання.

Нагадування вимкнені за замовчуванням для всіх підписників. Кнопка «Нагадування за 20 хв» дозволяє ввімкнути їх або вимкнути. При перевірці кожні 5 хвилин вони надходять приблизно за 15–20 хвилин. Вони використовують лише датований уманський графік.
